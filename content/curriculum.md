# Kurikulum Pembelajaran C (Dasar ke Menengah)

## Level 1 — Fondasi Algoritma
**Materi:**
- Pengertian algoritma.
- Pseudocode dan flowchart sederhana.
- Urutan langkah logis.

**Learning Outcome:**
- Siswa dapat menuliskan algoritma sederhana untuk masalah sehari-hari.

## Level 2 — Struktur Dasar Bahasa C
**Materi:**
- Struktur program C (`#include`, `main`, blok kode).
- Tipe data dasar (`int`, `float`, `char`).
- Variabel dan konstanta.

**Learning Outcome:**
- Siswa mampu membuat program C sederhana yang bisa dikompilasi.

## Level 3 — Sintaks dan Input/Output
**Materi:**
- Aturan sintaks dan tanda titik koma.
- `printf` untuk output.
- `scanf` untuk input.

**Learning Outcome:**
- Siswa dapat menerima input pengguna dan menampilkan hasil olahan data.

## Level 4 — Percabangan
**Materi:**
- `if`, `if-else`, `if-else if`.
- `switch-case`.

**Learning Outcome:**
- Siswa dapat membuat keputusan program berdasarkan kondisi.

## Level 5 — Perulangan
**Materi:**
- `for`.
- `while`.
- `do-while`.

**Learning Outcome:**
- Siswa dapat menyelesaikan pekerjaan berulang secara efisien.

## Level 6 — Array
**Materi:**
- Deklarasi array 1 dimensi.
- Input dan output elemen array.
- Iterasi array untuk statistik sederhana (min, max, rata-rata).

**Learning Outcome:**
- Siswa dapat menyimpan dan memproses kumpulan data dalam program.

## Level 7 — Fungsi
**Materi:**
- Deklarasi dan definisi fungsi.
- Parameter dan nilai balik.
- Pemecahan program menjadi modul.

**Learning Outcome:**
- Siswa dapat menulis program yang terstruktur, reusable, dan mudah dibaca.
