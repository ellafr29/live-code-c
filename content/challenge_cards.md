# Kartu Tantangan Live Coding

## Format Kartu
- **Judul Tantangan**
- **Level** (1-7)
- **Tujuan**
- **Batasan**
- **Contoh Input/Output**
- **Kriteria Lulus**

## Daftar Tantangan

### 1) Halo, C!
- **Level:** 1
- **Tujuan:** Menampilkan teks "Halo, C!" ke layar.
- **Batasan:** Hanya boleh gunakan `main` + `printf`.
- **Kriteria Lulus:** Output sama persis.

### 2) Kalkulator Sederhana
- **Level:** 3
- **Tujuan:** Menerima 2 bilangan dan menampilkan jumlah.
- **Batasan:** Gunakan `scanf` dan `printf`.
- **Kriteria Lulus:** Program berjalan untuk input positif dan negatif.

### 3) Ganjil atau Genap
- **Level:** 4
- **Tujuan:** Tentukan apakah angka termasuk ganjil/genap.
- **Batasan:** Wajib menggunakan `if-else`.
- **Kriteria Lulus:** Seluruh test case paritas lolos.

### 4) Menu Nilai Huruf
- **Level:** 4
- **Tujuan:** Ubah nilai angka ke huruf (A-E).
- **Batasan:** Wajib `switch-case`.
- **Kriteria Lulus:** Mapping nilai sesuai rubrik.

### 5) Deret Bilangan
- **Level:** 5
- **Tujuan:** Cetak angka 1 sampai N.
- **Batasan:** Versi `for`, `while`, dan `do-while`.
- **Kriteria Lulus:** Ketiga versi menghasilkan output identik.

### 6) Statistik Array
- **Level:** 6
- **Tujuan:** Cari nilai minimum, maksimum, dan rata-rata dari array.
- **Batasan:** Input ukuran array dinamis sederhana.
- **Kriteria Lulus:** Hasil perhitungan benar untuk beberapa dataset.

### 7) Pecah Program dengan Fungsi
- **Level:** 7
- **Tujuan:** Refaktor kalkulator mini menjadi beberapa fungsi.
- **Batasan:** Minimal 3 fungsi terpisah.
- **Kriteria Lulus:** Program modular, bersih, dan lolos test fungsional.
