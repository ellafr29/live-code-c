# Bank Soal Evaluasi Kemampuan

## A. Pilihan Ganda
1. **Apa fungsi `scanf` dalam C?**
   - A. Menampilkan output
   - B. Menerima input pengguna
   - C. Menghitung ekspresi
   - D. Menghapus variabel
   - **Kunci:** B

2. **Manakah struktur percabangan yang tepat untuk banyak kondisi diskrit?**
   - A. `for`
   - B. `while`
   - C. `switch-case`
   - D. `do-while`
   - **Kunci:** C

## B. Soal Coding Singkat
1. Buat program yang membaca sebuah bilangan dan menampilkan faktorialnya.
2. Buat program untuk menghitung rata-rata dari N bilangan yang disimpan dalam array.
3. Buat fungsi `int max2(int a, int b)` yang mengembalikan nilai terbesar.

## C. Rubrik Penilaian
- **Benar fungsional (60%)**: output sesuai seluruh test case.
- **Kualitas kode (25%)**: keterbacaan, penamaan, struktur.
- **Efisiensi dasar (15%)**: penggunaan loop/fungsi yang tepat.
